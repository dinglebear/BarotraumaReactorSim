# Community reactor circuits

Put community auto-reactor circuits here in Blueprints `.txt` format (`name.txt`, or `name_reactor.txt` + `name_battery.txt`). If the pin wiring is not obvious from its labels, add `name.pins` with lines like `reactor in1 reactor.load_value_out`. Then `node sim/cli.js compare <name>,vanilla --profile all`, and `node sim/build_web.js` to show them on the master page.

Master page: https://claude.ai/artifact/H7Y1hxZhsLgqyyr8Gjuyw5
